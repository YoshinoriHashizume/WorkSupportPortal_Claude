# 検収書比較 テスト仕様書

本書は **検収書比較（receipt_comparison）** に関する **自動テストの方針・設計・詳細テストケース** を定義する。  
機能要件の正は [検収書比較_機能仕様書.md](./検収書比較_機能仕様書.md) とする。

| 項目 | 内容 |
|------|------|
| 対象プログラム | **検収書比較**（業務支援ポータル内） |
| 旧機能名 | 受領書比較(MARI) |
| 配置メニュー | 生産管理 > 検収書比較 > **完成品** / **支給品** |

## 2. 目的

| 目的 | 説明 |
|------|------|
| 旧ロジック再現 | WinForms 受領書比較(MARI) と同等の分類・保存・引き継ぎを保証する |
| 完成品/支給品分岐 | CSV/TXT 取込・MARI SQL・表示列の差異を固定する |
| 比較精度 | 品番・日付・数量の3項目一致で `〇`、不一致/片側のみで `×` |
| リファクタの安全網 | クリーンアーキテクチャ移行後も domain / usecase の契約を固定する |
| 外部依存の分離 | CI では実 Oracle に接続せず、MARI 取得はモックする |

## 4. テスト戦略

### 4.1 テストピラミッド

1. **単体テスト（最優先）** … `domain/comparison.py`, `domain/file_parser.py`, `domain/comparison_sort.py` 等
2. **ユースケーステスト** … Oracle / リポジトリ **モック** で `usecase_*.py`
3. **結合テスト** … Django views: 403/200、テンプレート、フォーム POST、CSV レスポンス
4. **手動/E2E（任意）** … 実ファイル・検証用 Oracle

### 4.2 共通原則

| 原則 | 内容 |
|------|------|
| 決定性 | 日付・ファイル内容は fixture 固定 |
| 秘密情報 | `ORACLE_*` をリポジトリ・ログに含めない |
| 本番 Oracle 非依存 | CI では実 Oracle に接続しない |
| ファイル | テスト用 CSV/TXT をメモリまたは一時ファイルで生成 |

### 4.3 実行方法

リポジトリルートで:

```bash
pytest application/receipt_comparison/tests/test_receipt_comparison.py application/receipt_comparison/tests/test_receipt_comparison_supplied_parts.py
pytest application/receipt_comparison/tests/test_receipt_comparison_usecases.py application/receipt_comparison/tests/test_receipt_comparison_pending.py
pytest application/receipt_comparison/tests/test_receipt_comparison_oracle_mari.py application/receipt_comparison/tests/test_receipt_comparison_model_registry.py
pytest application/receipt_comparison/tests/test_receipt_comparison_vendors.py application/receipt_comparison/tests/test_receipt_comparison_supplier_codes.py
pytest config/tests/test_clean_architecture.py -k receipt_comparison
pytest -k "TC_RCV"    # TC-ID をテスト名に含める場合
```
