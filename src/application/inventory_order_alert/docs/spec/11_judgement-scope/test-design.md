## 1. 方針

- 基準日は **2026-10-27** に固定する
- **最優先は「算出が 1 行も変わらないこと」**（REQ-JS-NF-004）。在庫切れ日・発注期限・安全在庫・在庫シミュレーションの既存テストが**全件そのまま通る**ことを改修の条件にする
- 絞り込みは domain の純関数なので、**単体テストで境界値を固定する**
- 「判定に使わないが表示する」ことを**理由の文字列**と**保存フィールド**の両方で固定する
- JS に判定を持ち込んでいないことを**ソース文字列の検査**で固定する
