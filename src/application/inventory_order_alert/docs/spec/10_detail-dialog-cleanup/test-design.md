対応文書: [requirements.md](requirements.md)、[design.md](design.md)

## 1. 方針

- 基準日は **2026-09-18** に固定する
- **最優先は「判定が 1 件も変わらないこと」**（REQ-DDC-NF-001）。表示の再編なので、既存テストが全件そのまま通ることを改修の条件にする
- 見出し文は domain の純関数で対応区分ごとに固定する
- JS に文言が無いことを**ソース文字列の検査**で固定する
