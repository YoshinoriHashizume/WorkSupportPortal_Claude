# ユビキタス言語集（出荷トレンド一覧）

文書ID: UL-SHIPMENT-TREND-2026-001
作成日: 2026-07-30
更新日: 2026-07-30
対応文書: [ubiquitous_language_core.md](../../../docs/ubiquitous_language_core.md)（UL-CORE-2026-001）、[出荷トレンド一覧_機能仕様書.md](./出荷トレンド一覧_機能仕様書.md)（REQ-SHIPMENT-TREND-2026-001）

本書は **営業（出荷トレンド一覧）** コンテキスト固有の用語を定義する。

> **品番の呼称についての注意**: 本アプリの集計キーは `T_SHIP.ITEM_CD`＝**内作品番**（core V-006）であり、**得意先品番**（core V-005 = `CUST_ITEM_CD`）ではない。
> 一覧列・CSV・フィルタの表示名は **内作品番** とする。在庫発注アラートの「得意先品番」列とは別項目であるため、同一視してはならない。

プロジェクト横断の用語（比較基準年 V-003・データ初年度 V-007・集計基準年 T-002・予測込み合計 T-003）は
[ubiquitous_language_core.md](../../../docs/ubiquitous_language_core.md) を正とし、本書では重複定義しない。

> **年の呼称についての注意**: 本コンテキストには「年」に関する用語が 3 つあり、混同が最も起きやすい。
> - **データ初年度**（core V-007）… 最初に出荷があった暦年。自動・変更不可
> - **比較基準年**（core V-003）… 変動の分母となる暦年。既定はデータ初年度、手動で上書き可
> - **集計基準年**（core T-002）… 集計基準日が属する暦年
>
> **「初年度」「今年度」を単独で用いてはならない。** いずれの語も上記 3 つのどれを指すかが一意に定まらない。

## 1. バリューオブジェクト

### V-401: 変動数

- **英語名**: `ChangeQuantity`
- **定義**: `集計基準年の予測込み合計 − 基準年出荷合計`。得意先 × 内作品番ごとに算出する。
- **使用しない表現**: 「増減数」「差分数量」「変化量」

### V-402: 変動率

- **英語名**: `ChangeRate`
- **定義**: `(変動数 ÷ 基準年出荷合計) × 100`（%）。基準年出荷合計が 0 かつ集計基準年が正のときは算出せず `—` を表示する。
- **使用しない表現**: 「増減率」「変化率」「伸び率」
- **補足**: 一覧の既定ソートキー（昇順＝マイナス幅が大きい順）。警告色（S-401）の判定に用いる。

### V-403: 基準年出荷合計

- **英語名**: `BaselineYearTotal`
- **定義**: 比較基準年（core V-003）の暦年における月次出荷数量の合計。変動数・変動率の分母。
- **使用しない表現**: **「初年度出荷合計」**（比較基準年が手動設定されている場合はデータ初年度と一致しないため）

### V-404: 前年出荷合計

- **英語名**: `PreviousYearTotal`
- **定義**: `集計基準日の暦年 − 1` の暦年における月次出荷数量の合計。
- **使用しない表現**: **「前年度出荷合計」**（列名としては用いない。集計基準年を基準とする相対年であることを明示するため「前年」とする）。なお「年度」という語自体は暦年を指す表記として許容される（core T-002 補足）

### V-405: 月次予測

- **英語名**: `MonthlyForecast`
- **定義**: 集計基準年の残り月に見込む 1 か月あたりの出荷数量。`当年 1 月〜集計基準月の出荷合計 ÷ 経過月数` を **切り上げ** た値。
- **使用しない表現**: 「見込み数量」「予測値」「平均出荷数」
- **補足**: 出荷のない月も 0 として経過月数・合計に含める。予測を加えた合計は 予測込み合計（core T-003）と呼ぶ。

### V-406: 回帰直線

- **英語名**: `RegressionLine`
- **定義**: 詳細グラフの実績点および予測点に対して通常の線形最小二乗法で求めた直線 `y = a + b·x`。
- **構成要素**: 傾き `b`（1 期間あたりの数量増減）・切片 `a`・決定係数 `R²`。
- **使用しない表現**: 「トレンドライン」「近似直線」「最小二乗直線」（凡例表記は「最小二乗法」とする）
- **補足**: 点が 2 未満のときは描画しない。一覧の列・ソートには用いない。

### V-407: 集計基準日

- **英語名**: `AsOfDate`（core V-008 の本コンテキストにおける呼称）
- **定義**: 一覧・グラフ・CSV の集計の基準となる日付。**データ更新を実行した日のサーバ暦日** とし、集計スナップショットに固定保存する（実装: `infrastructure/oracle/summary_aggregation.py` の `timezone.localdate(refresh_record.refreshed_at)`）。
- **構成要素**: 日付。データ更新を再実行するまで変わらない。
- **使用しない表現**: 「基準日」（単独）「集計日」「現在日付」
- **補足**: 集計基準年（core T-002）は本日付が属する暦年。前年出荷合計（V-404）・月次予測（V-405）・予測の開始月・比較基準年の候補上限は、すべて本日付から導出する。表示時に当日日付で再計算してはならない（スナップショットの値を用いる）。
  **集計基準月** は本日付が属する暦月を指す（月次予測 V-405 の経過月数の終端、および予測開始月の直前月）。5年9組の「基準月」（結果画面で表示中の月パネル）とは **別概念** であり、本コンテキストで「基準月」を単独で用いてはならない。

## 2. ステータス

### S-401: 警告色

- **英語名**: `TrendAlertTone`
- **定義**: 変動率（V-402）に応じた一覧行の背景色区分。減少強（薄赤）/ 減少弱（薄黄）/ 増加強（薄緑）/ 中立（白）の 4 段階。
- **使用しない表現**: 「アラート色」（本コンテキストでは「警告色」とする）
- **補足**: 在庫発注アラートと同一パレット（`.alert-row--*`）を共有する。閾値は既定 20% / 20% で UI から変更できる。
  行の色分けを指す語はコンテキストごとに異なる（資産棚卸結果=**行色区分** `row_tone`、在庫発注アラート=**行背景色** `alertRowClass`、本コンテキスト=**警告色**）。いずれも判定軸が異なるため統一しない。

### S-402: 表示単位

- **英語名**: `ChartGranularity`
- **定義**: 詳細グラフの集計粒度。**年** / **月** の 2 値。既定は **年**。
- **使用しない表現**: 「粒度」（単独）「集計単位」（集計単位は得意先×内作品番の粒度を指す語として区別する）
- **補足**: 年表示では比較基準年以降の各暦年の合計（集計基準年は予測込み合計）、月表示では実績月＋予測月を点とする。回帰直線（V-406）の対象点も本値に従う。
