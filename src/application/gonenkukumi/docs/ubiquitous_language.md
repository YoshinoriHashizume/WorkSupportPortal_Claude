# ユビキタス言語集（5年9組）

文書ID: UL-GONENKUKUMI-2026-001
作成日: 2026-07-30
更新日: 2026-07-30
対応文書: [ubiquitous_language_core.md](../../../docs/ubiquitous_language_core.md)（UL-CORE-2026-001）、[5年9組_機能仕様書.md](./5年9組_機能仕様書.md)（REQ-GONENKUKUMI-2026-001）、[MARI_Oracle_テーブル定義.md](./MARI_Oracle_テーブル定義.md)

本書は **生産管理（5年9組）** コンテキスト固有の用語を定義する。
プロジェクト横断の用語（得意先品番 V-005・内作品番 V-006）は
[ubiquitous_language_core.md](../../../docs/ubiquitous_language_core.md) を正とし、本書では重複定義しない。
「使用しない表現」の適用範囲の考え方は core に従う。

---

## 1. エンティティ

### E-501: 検索履歴

- **英語名**: `SearchHistory`
- **定義**: 検索 API が成功したときに保存する検索条件の記録。ユーザーごとに保持し、条件の再利用に用いる。
- **構成要素**: 得意先コード・得意先品番（core V-005）・品目任意変換値（V-501）・検索年月（V-502）・実行日時。**対象日付（V-503）と得意先名は保存しない。**
- **使用しない表現**: 「検索ログ」「履歴データ」
- **補足**: 同一ユーザー・同一条件の重複を許容し、画面表示では条件セットごとに最新 1 件を出す。実装は `GonenKukumiSearchHistory`。

## 2. バリューオブジェクト

### V-501: 品目任意変換値

- **英語名**: `ItemCodeOptionChangeValue`
- **定義**: 内作品番（core V-006）を解決する際に `M_CUST_ITEM.ITEM_CD_OPTION_CHANGE_VALUE` と照合する任意の値。未入力は `*` として扱う。
- **使用しない表現**: 「変換値」（単独）「オプション値」「任意値」

### V-502: 検索年月

- **英語名**: `SearchYearMonth`
- **定義**: 日次推移を表示する基準となる暦月（`yyyy/mm`）。
- **構成要素**: 下限は `2022/01`、上限は対象日付（V-503）の暦月から 6 か月後の暦月。範囲外の値は自動で範囲内に収める。
- **使用しない表現**: 「検索月」「対象年月」「基準月」（基準月は結果画面で表示中の月パネルを指す語として区別する。V-508）

### V-503: 対象日付

- **英語名**: `AsOfDate`（core V-008 の本コンテキストにおける呼称）
- **定義**: マスタの有効期間判定の基準となる日付（`yyyy/mm/dd`）。**利用者が検索画面で指定する**（既定は当日）。
- **使用しない表現**: 「基準日」（単独）「有効期間基準日」
- **補足**: 結果画面で複数月を表示する場合も、全表示月で同一の値を用いる。検索履歴には保存しない。
  在庫発注アラートの「BOM 基準日」・出荷トレンド一覧の「集計基準日」と同一の抽象概念（core V-008）だが、**決定方法が利用者指定である点が異なる**ため呼称を統一しない。

### V-504: 支給区分

- **英語名**: `ConsignmentType`
- **定義**: BOM 構成における支給の種別（`M_PS.CONS_TYP`）。**非支給**（`0`）/ **有償支給**（`1`）/ **無償支給**（`2`）。
- **使用しない表現**: 「支給タイプ」「有償無償区分」

### V-505: 手配区分

- **英語名**: `ArrangementType`
- **定義**: 仕入先への手配方法。`PROCESS_REQUEST_ISS_TYP='1'` のとき **加工依頼**、`KANBAN_FLG='1'` のとき **かんばん**。
- **使用しない表現**: 「発注区分」「手配方法」

### V-506: 前月残

- **英語名**: `PreviousMonthBalance`
- **定義**: 前月末時点で未消化のまま繰り越された数量。確定受注（T-505）・確定発注（T-512）に対して算出する。
- **構成要素**: 数量。日次系列（T-503）の日次 31 列とは別の専用列に表示する。
- **使用しない表現**: 「繰越残」「前月繰越」「残数」
- **補足**: 行計には前月残を **含める**（VBA `SUM(F:AK)` 相当）。

### V-507: 保管区

- **英語名**: `WarehouseCode`
- **定義**: BOM 構成子の保管倉庫を表すコード（`M_ITEM_RCV_WH.WH_CD`）。
- **構成要素**: 文字列。解決できない場合は **`?`** を表示する。
- **使用しない表現**: 「倉庫コード」「保管場所」「保管区分」

### V-508: 基準月

- **英語名**: `BaseMonth`
- **定義**: 結果画面・Excel において **検索年月（V-502）に対応する月パネル**（T-502）を指す語。前月・次月を追加したときの相対ラベル（前々月／前月／次月／次々月、`N か月前` / `N か月後`）の起点となる。
- **構成要素**: 暦月（`yyyy/mm`）。値は検索年月と常に一致する。
- **使用しない表現**: 「基準となる月」「中心月」「集計基準月」（集計基準月は出荷トレンド一覧の別概念＝集計基準日が属する暦月）
- **補足**: 画面上に `（基準）` の表記は出さず、月ラベルは年月のみを表示する。Excel の条件ブロックに出力する検索年月も本月とする。

## 3. 専門用語

### T-501: ブロック

- **英語名**: `ResultBlock`
- **定義**: 結果画面・Excel における表の単位。得意先の **出荷** ブロックと、仕入先の **入荷** ブロック（BOM 階層ごと）からなる。
- **構成要素**: ブロックキーは得意先が `得意先コード + 得意先品番`、仕入先が `階層 + 内作品番 + 仕入先コード`。
- **使用しない表現**: 「セクション」「明細表」「パネル」（パネルは月単位の表示枠を指す語として区別する）

### T-502: 月パネル

- **英語名**: `MonthPanel`
- **定義**: 結果画面において 1 つの暦月分のブロック（T-501）をまとめた表示枠。前月・次月を同一ページに追加できる。
- **使用しない表現**: 「月タブ」「月ブロック」
- **補足**: 月ラベルは基準月が年月のみ、以降は「前々月／前月／次月／次々月」、3 か月以上離れる場合は「N か月前」「N か月後」。

### T-503: 日次系列

- **英語名**: `DailySeries`
- **定義**: 1 行あたり **31 列固定** の日別数量の並び。当月に存在しない日は空白とし、休日は `M_CAL` に基づき色を付ける。
- **使用しない表現**: 「日別データ」「デイリー系列」
- **構成要素の補足（行計）**: **行計** は日次 31 列と前月残（V-506）の合計（VBA `SUM(F:AK)` 相当）。本日在庫（T-509）は行計列のみに値を置き、日次列・前月残列は空とする。

### T-504: 内示受注

- **英語名**: `ForecastOrder`
- **定義**: 得意先から確定前に示される受注の見込み（`T_UNCNFM_ODR`。VBA `NAIJI_GET1` 相当）。
- **使用しない表現**: 「内示」（単独）「受注見込み」「フォーキャスト」
- **補足**: 得意先ブロックの最上段に表示する。

### T-505: 確定受注

- **英語名**: `ConfirmedOrder`
- **定義**: 得意先から確定した受注（`T_ODR`）。**前月残（V-506）** と **日次** の 2 行に分けて表示する（VBA `JUCHUZAN_GET` / `KAKUTEI_GET1` 相当）。
- **使用しない表現**: 「確定注文」「受注確定」
- **補足**: 前月残の基準は `2022/10/01`。

### T-506: 統合受注

- **英語名**: `UnifiedOrder`
- **定義**: 内示受注（T-504）と確定受注（T-505）を統合した受注（`T_UNITE_ODR`。VBA `TOUGOU_GET1` 相当）。
- **使用しない表現**: 「合計受注」「マージ受注」

### T-507: 売上実績

- **英語名**: `SalesRecord`
- **定義**: 売上として計上された実績（`T_SALES_TEMP`。VBA `URIAGE_GET` 相当）。**出荷実績（T-508）とは別の概念** であり、計上日が異なりうる。
- **使用しない表現**: 「売上」（単独）「請求実績」

### T-508: 出荷実績

- **英語名**: `ShipmentRecord`
- **定義**: 得意先へ出荷した実績（`T_SHIP`。VBA `SKDATA_GET` 相当）。
- **使用しない表現**: 「出荷」（単独）「出荷数」

### T-509: 本日在庫

- **英語名**: `CurrentStock`
- **定義**: 対象日付（V-503）時点の在庫（`T_ITEM_STOCK` の合計）。得意先ブロックでは内作品番、仕入先ブロックでは構成子の在庫を示す。
- **構成要素**: 数量。**行計列のみに表示** し、前月残・日次列は空とする。
- **使用しない表現**: 「現在在庫」「在庫数」（在庫数は在庫発注アラートの別概念）

### T-510: 月初発注

- **英語名**: `MonthlyInitialOrder`
- **定義**: 月初に仕入先へ示す発注の見込み（`T_U_MONTHLY_ODR_WORK`。VBA `NAIJI_GET2` 相当）。同一日に複数ある場合は **後の行を採用** する。
- **使用しない表現**: 「月初内示」「月次発注」

### T-511: 所要量

- **英語名**: `RequiredQuantity`
- **定義**: BOM 展開から算出した必要数量（`T_OD` + `T_RLSD_PUCH_ODR`、`OD_TYP='2'`。VBA `SYOYOU_GET` 相当）。
- **使用しない表現**: 「必要数」「要求量」「所要数量」

### T-512: 確定発注

- **英語名**: `ConfirmedPurchaseOrder`
- **定義**: 仕入先へ確定した発注。**前月残（V-506）** と **日次** の 2 行に分けて表示する（VBA `CHUZAN_GET` / `KAKUTEI_GET2` 相当）。
- **使用しない表現**: 「発注確定」「確定注文」

### T-513: 入荷実績

- **英語名**: `IncomingRecord`
- **定義**: 仕入先から入荷した実績（VBA `NYDATA_GET` 相当）。
- **使用しない表現**: 「入荷」（単独）「受入実績」「仕入実績」
