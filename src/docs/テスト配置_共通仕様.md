# テスト配置 共通仕様

各 Django アプリ配下に `tests/` を置き、単体テストをアプリ単位で管理する。

---

## 1. ディレクトリ構成

```
WorkSupportPortal/
├── conftest.py                 # pytest 共通（DB ガード等）
├── pytest.ini                  # testpaths = applications config
├── application/
│   ├── asset_inventory/tests/
│   ├── gonenkukumi/tests/
│   ├── identity/tests/
│   ├── inventory_order_alert/tests/
│   │   └── fixtures/           # アプリ固有 fixture
│   ├── portal/tests/
│   ├── receipt_comparison/tests/
│   │   └── fixtures/
│   └── shipment_trend/tests/
└── config/tests/               # プロジェクト横断（クリーンアーキテクチャ・本番手順等）
```

---

## 2. 実行方法

| 対象 | コマンド例 |
|------|-----------|
| 全体 | `pytest` |
| 1 アプリ | `pytest application/inventory_order_alert/tests/` |
| 1 ファイル | `pytest application/shipment_trend/tests/test_list_filter.py` |
| 横断規約 | `pytest config/tests/test_clean_architecture.py` |

`pytest.ini` の `testpaths = applications config` により、`tests/` トップレベルは使わない。

---

## 3. fixture の置き場所

| 種別 | 配置 |
|------|------|
| アプリ固有 CSV / TXT | `application/{app}/tests/fixtures/` |
| テスト内からの参照 | `Path(__file__).resolve().parent / "fixtures" / "..."` |
| プロジェクトルート参照 | `Path(__file__).resolve().parents[3]`（`application/{app}/tests/` から） |
