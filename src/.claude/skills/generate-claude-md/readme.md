

### 使い方

**既存プロジェクトの場合:**
```
「CLAUDE.mdをテンプレートから作り直して。既存のCLAUDE.mdから情報を引き継いで」
```

**新規プロジェクトの場合:**
```
「新しいプロジェクトのCLAUDE.mdを作成して」
```

### 動作の流れ

```
Step 1: テンプレートを読み込む
  ↓
Step 2: 既存CLAUDE.mdから情報抽出（or ユーザーに質問）
  ↓
Step 3: セクション1-2をプロジェクト情報で埋める
        セクション3-5はテンプレートのまま維持
  ↓
Step 4: ユーザーに確認
  ↓
Step 5: CLAUDE.md + referenceファイルを保存
```

### ポイント

**セクション3〜5は絶対に変更しない**: テンプレートのSDDルール・絶対ルール・Task Documentationはプロジェクト非依存なので、そのまま維持する指示を明記しています。

**referenceファイルへの分離を提案**: 既存CLAUDE.mdから抽出した詳細情報（開発コマンド、アーキテクチャ、命名規則等）は、CLAUDE.mdには含めず、設計レビュースキルのreferenceとして管理することを提案します（実際の保存はユーザー判断）。
