# 要件定義書テンプレート

このファイルは make-requirements スキルが参照する要件定義書の雛形である。

- **【必須】** の付いたセクションは必ず記述する（requirements-review-l1 の必須セクション定義に対応）。
- **【条件付き】** の付いたセクションは、機能の性質に応じて追加する。該当しない場合は入れない（薄い章を作らない）。
- 波括弧 `{ }` はプレースホルダ。実際の値に置き換える。
- 要件IDは既定でシンプル形式（`REQ-F-001` / `REQ-NF-001`）。衝突の恐れがある場合のみ機能名入り（`REQ-{FEAT}-F-001`）。
