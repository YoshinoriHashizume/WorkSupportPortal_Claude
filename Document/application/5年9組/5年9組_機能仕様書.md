# 5年9組 機能仕様書

本書は、Excel マクロ相当の生産管理参照機能を **業務支援ポータル上の Web アプリ** として提供するための要件を定義する。  
現行実装（`apps/gonenkukumi/`）を正とし、検索・結果表示・履歴・Excel 出力・Oracle 参照を **実装可能な粒度** で固定する。

## 2. 背景・業務目的

### 2.1 背景

生産管理では、得意先品目を軸に **内示・確定受注・出荷・仕入・入荷** の日次推移を Excel マクロ（5年9組）で参照してきた。本アプリは同等ロジックを Web 化し、ポータル認証・検索履歴・ブラウザからの結果閲覧・Excel ダウンロードを提供する。

### 2.2 本機能の目的

| 目的 | 内容 |
|------|------|
| 検索の効率化 | 得意先・品目・検索年月・対象日付で Oracle 一括検索し、結果を新規タブで表示 |
| 履歴の活用 | ユーザーごとに直近検索を PostgreSQL に保存し、条件の再利用を支援 |
| 複数月の比較 | 結果画面で前月・次月を同一ページ内に追加表示 |
| 帳票互換 | Web 表示と同構成の Excel を出力（VBA 色・行順・31 日列を維持） |

## 3. システム境界・前提

| 区分 | 内容 |
|------|------|
| 基幹 Oracle | **参照のみ**（SELECT）。ブラウザから直結しない。接続は `ORACLE_*` 環境変数 |
| ポータル PostgreSQL | **検索履歴のみ**（結果スナップショットは保存しない） |
| データ鮮度 | 結果画面・Excel は **リクエスト都度** Oracle 再検索（履歴 ID による再表示は行わない） |
| 認証 | Django 認証必須。未ログインは `/login`、API は 401 |
| 権限 | **生産管理** メニューグループまたは管理者（§9） |
| 複数会社 | `MARI_COMPANY_CD` 設定時、Oracle クエリに会社コード条件を付与。未設定時は条件なし |

## 4. 画面（ルーティング）

| 画面 ID | 画面 | ルート | 概要 |
|---------|------|--------|------|
| SCR-01 | 検索画面 | `/app/production/five-year-nine` | 検索条件・履歴（直近20件） |
| SCR-02 | 結果画面 | `/app/production/five-year-nine/result` | クエリで Oracle 再検索・複数月表示・Excel 出力 |

### 4.1 検索画面（SCR-01）

#### 4.1.1 入力項目

画面レイアウト順（上から）: 得意先 → 得意先品目 → 品目任意変換値 → **検索年月と対象日付を同一行** → **検索ボタン** → **エラー表示**（ボタン直下）。

| 項目 | キー | 型/形式 | 必須 | 既定値 | 備考 |
|------|------|---------|------|--------|------|
| 得意先 | `custCode` | string | 必須 | — | `includes/customer_select.html`。`M_CUST` を SSR + `GET /api/gonenkukumi/customers`。表示 `コード - 名称` |
| 得意先品目 | `custItem` | string | 必須 | — | 得意先未入力時 **disabled**。変更時クリア（履歴反映時除く） |
| 品目任意変換値 | `optionChange` | string | 任意 | `*` | 空は `*` |
| 検索年月 | `yearMonth` | `yyyy/mm` | 必須 | 注記参照 | 月選択 UI（自由入力不可） |
| 対象日付 | `asOfDate` | `yyyy/mm/dd` | 必須 | 当日 | UI は `type=date`、API はスラッシュ形式 |

**検索年月 UI**

- 下限 `2022/01`、上限は対象日付の暦月から **6 か月後** の暦月。
- 初期値は今日の暦月を min〜max に **クランプ**。
- 対象日付変更で範囲外になった検索年月は **自動クランプ**。

**ブラウザ候補の抑止**: フォーム・得意先・品目に `autocomplete="off"`。候補はアプリ側 Oracle データを優先。

#### 4.1.2 操作・レイアウト

- **ページ見出し**: `portal-page-title-row` にタイトル・お気に入りハート・説明文（`portal-page-description`：`得意先品目の内示・受注・出荷・仕入・入荷の推移を検索します。`）を横並び配置する。
- **検索**: `POST /api/gonenkukumi/search` 成功後、同一条件をクエリに載せ **新規タブ** で SCR-02 を開く。検索画面は **refresh** して履歴更新。
- **履歴クリック**: 条件をフォームへ反映（**即時検索なし**）。**対象日付は変更しない**。
- **レイアウト**: `portal-section-head` + 2 列グリッド。左 `gonen-search-sidebar`（最大 **380px**）、右 `db-table-card` 履歴表。履歴下余白 **16px**。入力高 40px。

#### 4.1.3 履歴表示

- SSR: 条件セットごとに **最新1件**、最大 **20件**。
- 列: 得意先／得意先品目／品目任意変換値／検索年月／検索日時（得意先は `コード - 名称`）。対象日付列なし。
- `.db-table-wrap` 内スクロール、ヘッダ **sticky**。
- API `/api/gonenkukumi/history` は最大 **50件**。

#### 4.1.4 得意先品目オートコンプリート

- 得意先確定時に `GET /api/gonenkukumi/cust-items` を **1回**、全件キャッシュ。
- 入力 **1文字目から** `startsWith` 絞込（API 再呼び出しなし）。表示上限 **1000件**。
- 取得中は「一致なし」を出さない。完了後 0 件なら赤字 **「一致する得意先品目がありません。」**

### 4.2 結果画面（SCR-02）

- クエリ（`custCode`, `custItem`, `optionChange`, `yearMonth`, `asOfDate`, 任意 `months`）を検証し **Oracle 再問い合わせ**。履歴テーブルは参照しない。
- 得意先表示: **`得意先名(得意先コード)`**。タイトルも同形式 + 品目。
- **ブロック**: 得意先 **出荷**／仕入先 **入荷（BOM 階層ごと）**。**TOTAL 合計表は Web/Excel とも非表示**。
- **複数月**: 初期は基準月のみ。「前月を追加」「次月を追加」で **同一ページ内** に月パネル追加。ブロックキー: 得意先 `custCode+custItem`、仕入 `kaiso+itemCd+vendCd`。
- **月ラベル**: 基準月は年月のみ（`（基準）` 非表示）。前々月／前月／次月／次々月、3か月以降は `Nか月前` / `Nか月後`。
- **`asOfDate`**: 全表示月で固定（マスタ有効判定の基準）。表示は `YYYY/MM/DD`。
- **日次列**: 常に **31列**。当月外日は空白 + `#b8c4d0`。休日は `M_CAL` に基づきテーマ色。
- **数量**: `0` は空欄、非ゼロは **3桁カンマ**。行計は前月残込み（VBA `SUM(F:AK)` 相当）。在庫は **行計列のみ**（前月残・日次列は空）。
- **スクロール**: `bare-result-page` はページ縦スクロール可（`portal-app-page` の viewport 固定を無効化）。
- **Excel**: ボタン「Excelで出力」→ `GET /api/gonenkukumi/export`。`months` クエリで表示中の全月を出力。

## 6. Oracle データ取得ロジック

入口: `OracleGonenKukumiSearchGateway` → `infrastructure/oracle/client.py` の一括検索。

### 6.1 検索結果の構成

| キー | 内容 |
|------|------|
| `internalItemCd` | 内作品番 |
| `holidayDays` | 休日（1〜31） |
| `customerBlocks` | 得意先出荷ブロック配列 |
| `customerTotals` | 集計用（**Web/Excel では専用表示しない**） |
| `supplierBlocks` | 仕入先入荷ブロック（BOM 展開） |

### 6.2 内作品番（`NAISAK_NOT_FOUND`）

- `M_CUST_ITEM` を `CUST_CD`・`DLV_LOC_CD='*'`・`CUST_ITEM_CD`・`ITEM_CD_OPTION_CHANGE_VALUE`（空は `*`）で検索。
- VBA `NAISAK_GET` 準拠: 複数行時は **最後の `ITEM_CD`** を採用。
- 有効期間: `EFF_PHASE_IN_DATE <= asOfDate <= EFF_PHASE_OUT_DATE`（NULL は無効扱いしない）。

### 6.3 得意先ブロック（出荷）

- 内作品番に紐づく全得意先行（`M_CUST_ITEM` + `M_CUST`）。0 件時は入力 `custCode` でフォールバック 1 行。

**日次系列（VBA 対応）**

| 区分 | ソース |
|------|--------|
| 内示受注 | `T_UNCNFM_ODR`（`NAIJI_GET1`） |
| 確定受注（前月残） | `T_ODR`（`JUCHUZAN_GET`、`2022/10/01` 基準） |
| 確定受注（日次） | `T_ODR`（`KAKUTEI_GET1`） |
| 統合受注 | `T_UNITE_ODR`（`TOUGOU_GET1`） |
| 出荷実績 | `T_SHIP`（`SKDATA_GET`） |
| 売上実績 | `T_SALES_TEMP`（`URIAGE_GET`） |
| 本日在庫 | `T_ITEM_STOCK` 合計（行計のみ） |

### 6.4 仕入先ブロック（BOM・外注）

- 起点: 内作品番 + `M_ITEM.SUB_ITEM_CD_01`〜`05`。`M_PS` CONNECT BY、`asOfDate` で有効期間。
- 同一 `COMP_ITEM_CD` は先頭のみ。`OUTSIDE_TYP = '2'`（外注）のみ。
- 仕入先: VBA `SICODE_GET2` 準拠、**最後の行**採用。保管区 `M_ITEM_RCV_WH.WH_CD`、無ければ `?`。
- 手配区分: `PROCESS_REQUEST_ISS_TYP='1'`→加工依頼、`KANBAN_FLG='1'`→かんばん。

**日次系列**

| 区分 | ソース |
|------|--------|
| 月初発注 | `T_U_MONTHLY_ODR_WORK`（`NAIJI_GET2`、同一日後勝ち） |
| 所要量 | `T_OD` + `T_RLSD_PUCH_ODR`（`SYOYOU_GET`、`OD_TYP='2'`） |
| 確定発注（前月残） | `CHUZAN_GET` |
| 確定発注（日次） | `KAKUTEI_GET2` |
| 入荷実績 | `NYDATA_GET` |
| 本日在庫 | 構成子の `T_ITEM_STOCK` |

### 6.5 休日・支給区分

- `M_CAL`: `HOLIDAY_FLG` Trim 後 `'0'` 以外または Null が休日。
- `M_PS.CONS_TYP` → 支給区分（0:非 / 1:有償 / 2:無償）。

詳細テーブル・列定義は [MARI_Oracle_テーブル定義.md](./MARI_Oracle_テーブル定義.md) を参照。

## 7. 表示・Excel 出力仕様

### 7.1 Web / Excel 共通グリッド

- 日次列 **31 固定**（`GONEN_REPORT_GRID_DAYS = 31`）。無効日 `#b8c4d0`。
- 外枠・区分セル・休日列はセクション `theme`（`bg` / `lightBg` / `veryLightBg` / `section-border`）。
- グリッド内枠 `#E2E8F0`。
- テーマ色: 得意先 index=1、仕入先 index=2+`kaiso`（黄金角 HSL、`section_theme_for_supplier`）。

### 7.2 行順

- **得意先**: 内示受注 → 確定受注 → 統合受注 → 出荷実績 → 売上実績 → 本日在庫。
- **仕入先**: 月初発注 → 所要量 → 確定発注 → 入荷実績 → 本日在庫。

### 7.3 Excel 出力

| 項目 | 内容 |
|------|------|
| API | `GET /api/gonenkukumi/export` |
| シート名 | `検索結果`（先頭タイトル行なし） |
| ファイル名 | `{custCode}_{custItem}_{yyyyMM}_{yyyyMMddHHmmss}.xlsx`（東京時刻） |
| フォント | MS PGothic |
| 数値 | `#,##0`、`0` は空欄 |
| 条件ブロック | A列項目名・B列値。検索年月は **基準月のみ** `YYYY/MM` |
| 複数月 | Web と同じ月パネル順・見出し・テーマ色 |
| 固定枠 | 7/8 行間 freeze（`A8` 相当） |
| 列幅 | AutoFit 相当 + `bestFit`、結合セル除外 |

## 8. API 仕様（ポータル）

### 8.1 `POST /api/gonenkukumi/search`

- **認証**: 必須（401）
- **入力 JSON**: `custCode`, `custItem`, `optionChange`, `yearMonth`, `asOfDate`
- **処理**: Oracle 検索 → 成功時のみ履歴 INSERT
- **成功**: `{ "ok": true }` または `{ "success": true }`（実装の JSON 契約に合わせる）
- **失敗**: 400 入力不正 / 404 `NAISAK_NOT_FOUND` / 502 Oracle / 503 未設定

### 8.2 `GET /api/gonenkukumi/customers`

- **認証**: 必須
- **処理**: `M_CUST` 最大 500 件、**数字3桁コードのみ**
- **成功**: `{ "items": [{ "custCode", "custName" }] }` または `loadError` 付き空配列

### 8.3 `GET /api/gonenkukumi/history`

- **認証**: 必須
- **応答**: 最大 50 件、`optionChange` 含む（§5）

### 8.4 `POST /api/gonenkukumi/oracle-result`

- **認証**: 必須
- **入力**: §8.1 と同形
- **成功**: `{ "ok": true, "oracle": { ... } }`。**履歴 INSERT なし**（補助 API）

### 8.5 `GET /api/gonenkukumi/cust-items`

- **認証**: 必須
- **クエリ**: `custCode`, `asOfDate` 必須
- **成功**: `{ "items": ["品目", ...] }`

### 8.6 `GET /api/gonenkukumi/export`

- **認証**: 必須
- **クエリ**: SCR-02 と同形 + `months`（表示月リスト）
- **応答**: `application/vnd.openxmlformats-officedocument.spreadsheetml.sheet`

### 8.7 `GET /api/gonenkukumi/cust-item-suggestions`（任意）

- クエリ `q` 3 文字以上のサーバ検索型。**現行 UI は未使用**（§4.1.4 プリフェッチのみ）。

### 8.8 エラー応答（共通）

| code | HTTP |
|------|------|
| `ORACLE_NOT_CONFIGURED` | 503 |
| `NAISAK_NOT_FOUND` | 404 |
| その他 Oracle | 502 |
