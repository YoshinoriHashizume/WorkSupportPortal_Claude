## 2. 目的

| 目的 | 説明 |
|------|------|
| 回帰防止 | 検索年月境界・VBA 準拠 Oracle 集計・複数月表示が仕様どおりであることを保証する |
| リファクタの安全網 | クリーンアーキテクチャ移行後も domain / usecase の契約を固定する |
| 外部依存の分離 | CI では実 Oracle に接続せず、ドメイン単体・モック結合を最優先する |
| 受入の明文化 | 自動検証範囲と手動・ステージング検証の境界を固定する |

## 4. テスト戦略

### 4.1 テストピラミッド

1. **単体テスト（最優先）** … `domain/`・`infrastructure/oracle/client.py` の純関数・SQL 断片（偽カーソル）
2. **ユースケーステスト** … Oracle / 履歴リポジトリ **モック** で `usecase_*.py`
3. **結合テスト** … Django views: 401 / 400 / 404 / 502 / 200、テンプレート属性
4. **E2E（任意）** … Playwright でログイン・検索スモーク

### 4.2 共通原則

| 原則 | 内容 |
|------|------|
| 決定性 | `today_ym` 等は引数化または固定日付注入 |
| 秘密情報 | `ORACLE_*` をリポジトリ・ログに含めない |
| 本番 Oracle 非依存 | CI では実 Oracle に接続しない |
| Excel | バイト完全一致は行わない。シート名・セル値・書式を検証 |

### 4.3 実行方法

リポジトリルートで:

```bash
pytest applications/gonenkukumi/tests/test_gonenkukumi_domain.py applications/gonenkukumi/tests/test_gonenkukumi_domain_errors.py
pytest applications/gonenkukumi/tests/test_gonenkukumi_application.py applications/gonenkukumi/tests/test_gonenkukumi_views.py
pytest applications/gonenkukumi/tests/test_gonenkukumi_excel_export.py applications/gonenkukumi/tests/test_oracle_customers.py
pytest -k "TC-YM"    # TC-ID で絞り込み（テスト名に含める場合）
pytest config/tests/test_clean_architecture.py -k gonenkukumi
```

## 6. テストデータ方針

### 6.1 検索条件 fixture

| ケース | custCode | custItem | yearMonth | asOfDate | 期待 |
|--------|----------|----------|-----------|----------|------|
| 正常 | `100` | `ITEM-1` | `2024/06` | `2024/06/15` | 検証成功 |
| 得意先空 | `""` | `ITEM-1` | `2024/06` | `2024/06/15` | 失敗 |
| 形式不正 | `100` | `ITEM-1` | `2024-06` | `2024/06/15` | 失敗 |

### 6.2 検索年月 fixture

| 関数 | 入力 | 期待 |
|------|------|------|
| `compare_ym` | `2024/01`, `2024/02` | 負 |
| `year_month_bounds` | asOf `2024/06/15` | min `2022/01`, max `2024/12` |
| `clamp_ym` | `2020/01` | `2022/01` |

### 6.3 履歴 fixture

同一ユーザーで `custCode+custItem+optionChange+yearMonth` が同じ履歴を複数 INSERT → API/SSR は **最新1件のみ** 表示。

### 6.4 Oracle SQL fixture（偽カーソル）

| TC 観点 | VBA 相当 |
|---------|----------|
| 所要量 | `SYOYOU_GET` |
| 確定受注前月残 | `JUCHUZAN_GET` |
| 仕入先最後行 | `SICODE_GET2` |
| 月初発注キー | `NAIJI_GET2` |
